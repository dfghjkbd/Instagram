# Elevate Trend – Social Media Monitoring Tool

## 📌 Project Overview

Elevate Trend is a Django-based social media monitoring tool developed as a final-year B.Tech group project. The system helps analyze and visualize social media data from platforms like Facebook and Instagram to understand engagement, trends, and user behavior.

---

## 🚀 Features Implemented

### 🔐 Authentication

* User signup and login functionality


### 🔗 Social Media Integration

* Facebook OAuth integration
* Instagram OAuth integration
* Fetching user data such as:

  * Access token
  * Profile details
  * Page information

### 📊 Data Collection & Storage

* Fetching Facebook page insights
* Collecting Instagram account data
* Storing data in MySQL database (Hostinger)

### 📈 Analytics & Insights

* Displaying post insights and engagement metrics
* Combining video details and analytics
* Basic trend analysis using collected data

### 📉 Data Processing

* Data ingestion and transformation
* Handling API responses and structuring them
* Managing real-time and batch data

### 🌐 Web Application

* Built using Django framework
* Hosted using Apache server on Hostinger
* Dynamic HTML pages for visualization

---

## 🛠️ Tech Stack

* Backend: Django (Python)
* Database: MySQL
* Frontend: HTML, CSS
* APIs: Facebook Graph API, Instagram API
* Hosting: Hostinger (Apache)

---

## ⚙️ Key Functionalities

* User logs in using social media accounts
* System fetches and stores social media data
* Displays insights in a structured format
* Helps in analyzing engagement trends
